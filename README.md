# DST Mods

> 饥荒联机版（Don't Starve Together）Mod 仓库，每个 Mod 使用独立子目录。

## Mod 列表

### [Repairable Gear Stays](no-break-repairables/README.md)

**让可修复的装备在耐久耗尽后保留下来，修好即可继续使用。** 战斗或探索时来不及修理，也能把装备留到事后，通过加燃料、喂食、缝补或材料修复恢复使用。

装备的耐久照常消耗。归零后，正在穿戴的装备会自动卸下，破损期间无法重新装备，护甲也不再提供减伤；耐久修复到大于零后，便可重新装备并恢复原有效果。补充燃料、喂食和缝补等修复操作仍需消耗相应材料。

#### 支持的物品

| 物品 | 归零后的处理与修复方式 |
|---|---|
| 魔光护符 | 燃料耗尽后保留，补充噩梦燃料等适用燃料后恢复使用。 |
| 恐怖盾牌、眼面具 | 护甲归零后保留，通过喂食恢复耐久。 |
| 橙色护符等支持材料修复的装备 | 使用次数耗尽后保留，使用对应修复材料恢复。 |
| 雨衣、雨伞、眼球伞等可缝补装备 | 耐久耗尽后保留，使用缝纫工具修复。 |
| 伯尼 | 保留原版破损外观，取消破损后落地触发的延迟分解，缝补后恢复。 |
| 绝望石头盔、绝望石盔甲 | 归零后卸下；由持有者处于疯狂状态时触发第一段自修复，恢复少量耐久后即可重新穿戴，继续原版自修复。 |

破损雨伞和受支持的护甲仍保留原版自动换上备用装备的行为，背包里的旧破损装备也不会挡住健康备用品的选择。

#### 适用范围

- **服务端 Mod**：由房主或专用服务器安装启用，其他玩家无需单独安装。
- 支持有明确修复途径、原本耗尽后会消失的装备；不可修复的普通工具、武器和护甲保持原版行为。
- 不调整食物腐烂、建筑生命值或工作次数；亮茄、虚空、废铁等原本已有破损修复机制的装备保留原版机制。
- 第三方 Mod 装备的兼容性取决于其修复和耗尽逻辑，具体边界见详细说明。停用本 Mod 前，请先修好耐久为零的物品。

安装时将 `no-break-repairables` 子目录复制或软链接到游戏的 `mods` 目录，并在世界的 Mod 设置中启用 **Repairable Gear Stays**。
